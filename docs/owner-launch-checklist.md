# 官网正式启用：需要提供的资料

本轮已补图片素材库、封面与三语图片说明、首页推荐与栏目动态、正文标题/列表/粗体预览、内容复制、草稿历史恢复、备份导入、未保存修改提示、咨询筛选及批量状态处理。代码功能和正式上线是两件事，下面的账号和业务资料仍需落实。

## 现在优先准备

1. **正式内容**：艺人姓名与简介、作品名称与介绍、活动时间和场地、商品名称/价格/是否接受询价、对外联系资料。可以先给中文原稿，后续整理另外两种语言并核对；系统发布时需要三语内容齐全。
2. **授权图片**：艺人照、作品封面、海报、商品图及使用授权范围。后台支持 JPEG、PNG、WebP 静态图片，每张最多 2 MB / 2000 万像素。上传会压缩为网页图片并移除元数据，原图请自行留存。
3. **正式托管与数据库访问**：现有部署项目、公司镜像仓库和域名管理权限，以及 PostgreSQL 服务。沿用现有域名方案，不改动企业邮箱记录。数据库连接、管理员密码等密钥应配置在托管平台的私密环境变量中，不要放在聊天、代码或截图里。
4. **管理员和咨询负责人**：正式管理员登录邮箱、接收业务咨询的邮箱、由谁处理消息。当前适合单管理员使用；需要多人分工时再确定角色和权限。

## 按业务需要准备

- **自动邮件**：确定发信服务、已验证的发信域名/地址、管理员通知收件地址和访客回执文案。当前提交后有网页回执、后台可查看并手动回复，没有自动发信。
- **收款或售票**：只有需要在线交易时才准备商户账号、支付/票务平台、库存、配送或出票规则，以及退款取消规则。当前商品意向单不会扣款或占用库存。
- **运营规则**：确认咨询资料保存多久、删除流程、备份保留多久、异常时谁接收提醒，再据此整理对外说明。系统目前由管理员手动删除咨询。

## 已能自行操作的内容

- 管理入口：`/{locale}/manage`。本地中文入口为 `http://127.0.0.1:3000/zh-cn/manage`。
- 先上传素材，再到相应栏目创建内容、选封面并填写三语说明；勾选“推荐到首页”，审核并发布后才会在首页展示。
- 首页最多 6 条推荐；栏目页显示最近 3 条，完整列表保留在公开目录中。
- “内容恢复”先读取内容导出文件、列出条目。已有内容默认不选中，主动勾选后才替换草稿；公开版本和咨询不变。导入逐项进行，中断时保留已成功条目并显示数量。
- 内容导出不包含图片文件、咨询、会话或密码。完整恢复需要数据库及图片备份；导入时不存在的封面会明确提示并移除。
- 历史保留每条最多 5 版、全站最近 100 版；恢复为草稿后仍需重新审核发布。

## 正式开放前的验证

由实施方配置私密环境变量，执行数据库迁移和 `npm run platform:doctor`；数据库运行账号除内容表的 SELECT/UPDATE 外，需要媒体表的 SELECT/INSERT/DELETE。执行完整质量检查，再验证正式域名、HTTPS、登录、上传、发布、咨询和备份恢复。

`platform:doctor` 只读检查配置与存储，不输出密码、数据库连接串或咨询正文。它不替代真实部署验收，也不代表已经接通邮件、支付和监控。
